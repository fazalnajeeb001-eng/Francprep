# Project Rules & Behavioral Guidelines for Francprep Agentic AI Assistants

## 🚫 ZERO COMPROMISE ON VISUAL QUALITY
1. **NO SVG ILLUSTRATION FALLBACKS**: NEVER use line-art, sketch, or programmatic SVG illustration fallbacks for exam questions.
2. **HIGH DEFINITION PNG IMAGE STANDARD**: All visual illustration questions (Q1–Q4 in Compréhension Orale) must strictly use high-definition PNG image assets stored in `public/illustrations/tcf_p{paperNum}_q{qNum}.png`.
3. **PENDING IMAGE PLACEHOLDER STANDARD**: If a dedicated HD PNG image for a specific paper/question is pending generation (due to API rate limits), render a clean, professional HD card ("🎨 Illustration HD en cours de création") instead of any low-quality SVG or line-art drawing.
4. **100% UNIQUNESS & AUTHENTIC TCF FORMULATION**: Every question across all 10 papers must remain 100% unique with 0% overlap, following official France Éducation International (FEI) TCF Canada exam standards.
